# ZeTer Media Converter

Приложение для Windows: преобразование видео в MP3, объединение аудио курса
и разбивка на части до 10 часов. Также есть отдельный режим объединения видео.

Нужны Python с Tkinter и доступные в PATH `ffmpeg` и `ffprobe`.
Запуск из папки проекта: `python "ZeTer Media Converter.py"`.

Название программы — **ZeTer Media Converter**. Оно задаётся константой
`APP_NAME` в `videovaudio/app.py` и используется в интерфейсе и новых
диагностических отчётах. Файл запуска — `ZeTer Media Converter.py`.
Имена пакета `videovaudio` и публичного класса `VideoToAudioConverter`
сохранены для совместимости.

После завершения аудио- или видеозадачи готовые файлы перечисляются в уведомлении
справа внизу, поверх остальных окон. Оно не исчезает по таймеру: закрыть его можно
крестиком. Кнопка «Открыть расположение файла» открывает Проводник с выделенным
файлом и сохраняет уведомление. Результаты новой задачи добавляются сверху;
большой список прокручивается. Уведомление работает, пока открыта программа.

Код и владельцы модулей описаны в [архитектуре](docs/ARCHITECTURE.md),
последовательности обработки — в [FLOWS](docs/FLOWS.md),
проверки — в [VERIFICATION](docs/VERIFICATION.md).

При повторной обработке прежние MP3 сохраняются внутри
`Аудио для каждого видео/Предыдущие результаты/run_...`.
Файл `manifest.json` связывает исходные имена с резервными копиями.
Резервные копии автоматически не удаляются; после проверки нового результата
пользователь может удалить ненужные копии вручную.
