# ZeTer Media Converter

**Настольный конвертер видео и аудио для Windows.** Программа помогает превратить папку с видеолекциями или курсом в MP3 — отдельно для каждого видео и в виде последовательных частей длительностью до 10 часов. Есть второй режим: объединение видеозаписей в MP4-части до 10 часов.

[**Скачать EXE для Windows (v3.3.5)**](https://github.com/zeter1/ZeTer-Media-Converter/releases/download/v3.3.5/ZeTer-Media-Converter.exe) · [Все релизы](https://github.com/zeter1/ZeTer-Media-Converter/releases) · [История изменений](CHANGELOG.md) · [Как устроен проект](docs/ARCHITECTURE.md)

> **Для обычного использования Python устанавливать не нужно.** В опубликованный EXE уже включены Python, Tkinter, FFmpeg и FFprobe.

## Что умеет программа

| Возможность | Результат |
| --- | --- |
| Видео → MP3 | Отдельный MP3 для каждого найденного видео. |
| Аудиокурс по частям | Последовательные MP3 длительностью не более 10 часов каждый. |
| Объединение видео | Готовые MP4-части до 10 часов с выбором разрешения и битрейтов. |
| Очередь папок | Обработка нескольких курсов без повторного выбора каждого файла. |
| Контроль выполнения | Прогресс, отмена, журнал операций и уведомление о готовых файлах. |
| Сохранность результатов | Резервные копии предыдущих MP3; подготовка и проверка новых результатов перед публикацией. |

Поддерживается поиск видео в выбранной папке и её подпапках. Расширения для поиска: `.mp4`, `.avi`, `.mkv`, `.mov`, `.wmv`, `.flv`, `.webm`, `.mpeg`, `.mpg`, `.3gp`, `.m4v`, `.ts`. **Фактическая обработка зависит от кодеков и состояния конкретного файла**. Входные файлы сортируются естественным образом (например, `Урок 1`, `Урок 2`, `Урок 10`).

## Скачать и запустить на Windows

**Платформа:** Windows 10/11, x64. Актуальный опубликованный релиз — **3.3.5**.

1. Перейдите на страницу [**Release v3.3.5**](https://github.com/zeter1/ZeTer-Media-Converter/releases/tag/v3.3.5) и скачайте файл **`ZeTer-Media-Converter.exe`** из раздела **Assets** (или используйте прямую ссылку выше).
2. Поместите EXE в обычную папку с правом записи, например `Документы\ZeTer Media Converter`: рядом с программой создаётся папка **`Логи проблем`**.
3. Запустите EXE двойным щелчком. Установка, регистрация, Python и отдельная настройка FFmpeg не требуются.
4. Выберите вкладку нужного режима, добавьте папку с видео и запустите обработку.

**Важно о безопасности:** релизный EXE **не подписан цифровой подписью Authenticode**, поэтому Windows SmartScreen может показать предупреждение. Загружайте файл только со страницы релиза проекта. При сомнениях проверьте [SHA-256](https://github.com/zeter1/ZeTer-Media-Converter/releases/download/v3.3.5/ZeTer-Media-Converter.exe.sha256) и не запускайте файл, происхождение которого не подтверждено.

## Как пользоваться

### Режим 1. Преобразование видео в аудио (MP3)

1. Откройте вкладку **«Все видео в аудио по 10 часов и аудио для каждого видео.»**.
2. Нажмите **«➕ Добавить папку»** и укажите каталог с видеоуроками. Для нескольких курсов есть **«📂 Выбрать несколько»**.
3. Проверьте список папок и нажмите **«🚀 Запустить конвертацию в аудио»**.
4. Следите за прогрессом и сообщениями в окне. После успешного завершения появится уведомление с готовыми файлами; кнопка **«Открыть расположение файла»** откроет Проводник.

Файлы сохраняются **внутри выбранной папки курса**:

```text
Мой курс/
├── Урок 1.mp4
├── Урок 2.mkv
├── Аудио для каждого видео/            # отдельные MP3
│   └── Предыдущие результаты/          # резервные копии предыдущих MP3, если есть
└── Все видео в аудио по 10 часов/      # объединённое аудио, разбитое на части
```

При повторной конвертации прежние MP3 перемещаются в резервное хранилище **`Аудио для каждого видео/Предыдущие результаты/run_...`** после создания проверенных копий. Внутри сохраняется `manifest.json`. Резервные копии **не удаляются автоматически** — удаляйте их вручную только после проверки нового результата.

### Режим 2. Объединение видео (MP4)

1. Откройте вкладку **«Объединение всех видео по 10 часов»**.
2. Добавьте папку с записями курса.
3. Выберите настройки готового видео: **720p или 1080p**, битрейт видео и звука. Начальные значения в интерфейсе — **720p / 2500k / 160k**.
4. Нажмите **«🎬 Объединить видео по 10 часов»**.

Результат записывается в подпапку **`Объединение всех видео по 10 часов`** выбранного курса, как MP4-файлы `Часть 001.mp4`, `Часть 002.mp4` и далее. Программа обрабатывает видео в естественном порядке и применяет выбранные параметры с перекодированием.

**Во время обработки:** кнопка **«⏹️ Отмена»** запрашивает остановку текущей задачи. Входные видео не предназначены для удаления программой; тем не менее перед длительной обработкой важных материалов рекомендуется иметь отдельную копию исходников.

## Где искать результаты и что делать при ошибке

| Ситуация | Что проверить |
| --- | --- |
| Папка не добавляется | В каталоге должны быть поддерживаемые видеофайлы; проверьте также права доступа и вложенные папки. |
| Конвертация идёт медленно | Объединение, перекодирование и обработка больших курсов могут занимать длительное время; прогресс и этапы отображаются в окне. |
| Нет результата / задача завершилась с ошибкой | Посмотрите **«Лог операций»** и папку **`Логи проблем`** рядом с EXE. Проверьте свободное место и доступ на запись в папку курса. |
| Нужно найти готовый файл | Используйте уведомление после успешного завершения либо откройте указанные выше каталоги внутри курса. |
| Нужна помощь с ошибкой | Создайте [GitHub Issue](https://github.com/zeter1/ZeTer-Media-Converter/issues), указав версию, Windows, действия для воспроизведения, ожидаемый и фактический результат. |

Диагностика включает логи обработки, сведения о сбоях и итоговые отчёты. **Перед публикацией логов проверьте их содержание:** там могут быть локальные пути и названия личных медиафайлов. Не прикладывайте приватные видео, токены и конфиденциальные данные.

## Для разработчиков и технического ревью

Проект написан на **Python 3.12**, интерфейс реализован на **Tkinter**, обработка видео и аудио — через **FFmpeg/FFprobe**. Для поставки автономного Windows EXE используется **PyInstaller** и **GitHub Actions**.

### Архитектура и инженерные решения

Изначально крупный модуль приложения был разделён по зонам ответственности: UI, очереди, аудио, видео, запуск процессов, диагностика, хранение и операции с файлами. Входная точка `ZeTer Media Converter.py` создаёт приложение, а `videovaudio/app.py` собирает его из специализированных компонентов.

```text
ZeTer Media Converter.py     # точка входа / Tkinter
videovaudio/
  app.py                     # композиция приложения и состояние
  ui.py / queues.py          # интерфейс и управление очередями
  audio/                     # извлечение аудио, MP3, разбиение
  video/                     # нормализация, объединение, MP4
  process_runner.py          # subprocess, timeout, отмена
  diagnostics/               # ошибки, состояния, отчёты, целостность
  storage/                   # атомарные операции, логи, сканирование
  core/                      # общие FFmpeg/путь/аудиоконтракты
tools/                       # проверки, регрессионные тесты, индекс кода
docs/                        # архитектура, потоки и документация
```

Ключевые аспекты реализации:

- **Надёжность вывода:** промежуточные файлы, проверки длительности/параметров, публикация результата после валидации; для набора видео предусмотрено восстановление после ошибки публикации.
- **Безопасность повторного запуска:** предыдущие MP3 сохраняются с проверкой копий и `manifest.json` до освобождения выходных имён.
- **Управление процессами:** запуск FFmpeg как дочернего процесса, отмена, контроль времени выполнения и диагностический контекст ошибок.
- **Наблюдаемость:** структурированные события, журналы процесса, сводки запуска и сведения о незавершённом предыдущем сеансе.
- **Удобство сопровождения:** документация владельцев модулей и автоматически генерируемый индекс символов и вызовов в `docs/CODE_MAP.json` / `docs/CODE_INDEX.md`.

Подробности: [архитектура](docs/ARCHITECTURE.md) · [последовательности обработки](docs/FLOWS.md) · [маршрутизация по коду](docs/AI_NAVIGATION.md).

### Запуск из исходников

Требуются **Python с Tkinter** и доступные через `PATH` команды `ffmpeg` и `ffprobe`. Для исходного режима они **не включаются автоматически**, в отличие от EXE.

```powershell
git clone https://github.com/zeter1/ZeTer-Media-Converter.git
cd ZeTer-Media-Converter
python "ZeTer Media Converter.py"
```

### Тестирование и CI

```powershell
python tools/verify_project.py
python -B tools/test_audio_run_regressions.py
python -B tools/test_completion_notification.py
python -B tools/test_audio_regressions.py  # требуется FFmpeg/FFprobe в PATH
```

`verify_project.py` проверяет синтаксис, импорт, структуру публичного API, состав исходников и актуальность индекса кода. Регрессионные тесты покрывают жизненный цикл очереди, уведомления и сценарии обработки аудио, включая работу с настоящими тестовыми медиа.

На GitHub работают два раздельных сценария:

- [**Проверка исходников**](.github/workflows/validate.yml) — Windows runner, импорт/архитектура и регрессионные тесты без GUI.
- [**Сборка Windows EXE**](.github/workflows/build-windows.yml) — контролируемый релизный pipeline с PyInstaller, фиксированным FFmpeg, SHA-256, проверкой собранного EXE и публикацией GitHub Release. **Обычные изменения README не запускают новый релиз.**

См. [инструкции по проверке](docs/VERIFICATION.md), [порядок сборки](docs/BUILD_WINDOWS.md), [CHANGELOG](CHANGELOG.md), [последнюю успешную сборку v3.3.5](https://github.com/zeter1/ZeTer-Media-Converter/actions/runs/38154927135).

### Текущие ограничения

- Автоматически пройдены проверки исходников, аудиорегрессии и headless smoke-test упакованного EXE. **Полный пользовательский сценарий в настоящем GUI Windows, многочасовые курсы, особенности конкретных кодеков/оборудования — NOT VERIFIED**.
- Исполняемый файл для Windows x64 не подписан Authenticode; возможны предупреждения SmartScreen.
- Готовый файл в режиме PyInstaller `--onefile` при запуске распаковывает компоненты во временный каталог. Для диагностики программа должна иметь возможность создавать `Логи проблем` рядом с EXE.
- Сборка включает сторонние компоненты и их лицензионные материалы: [THIRD_PARTY_NOTICES.txt](packaging/THIRD_PARTY_NOTICES.txt). Для опубликованной версии они также доступны в [Assets релиза](https://github.com/zeter1/ZeTer-Media-Converter/releases/tag/v3.3.5).
